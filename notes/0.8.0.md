# hrdrhrdrhrdr 0.8.0

macOS release, build 35.

This update saves captured conversations on the Mac, adds more agent notifications and a Dock badge, and keeps the main window at a usable minimum size. The iPhone and iPad app is distributed separately; installing this macOS update does not update the iPhone and iPad app installed from TestFlight.

## Conversations saved on this Mac

- When **Show Conversations on iPhone and iPad** is turned on, captured conversations are now saved to a local database on this Mac. Before, they were kept in memory only.
- The database is readable only by your macOS account. Saved conversations survive a restart of the conversation collection process.
- A response is saved while it streams, shortly after it changes, and at once when the turn finishes. Only the messages that changed are written.
- Storage maintenance keeps up to 256 conversations, 256 MiB and 30 days, removing the least recently updated first. Conversations past these limits can remain while the proxy is off or if cleanup fails. Turning capture off keeps saved history.
- To delete saved conversations, use the clear button in Settings → iPhone and iPad. It asks for confirmation and is available while the proxy is running. A failed clear can leave some data behind. Backups, APFS snapshots and storage media may retain copies; clearing does not promise physical or cryptographic erasure.
- The files have no application-layer encryption and may contain sensitive text.

## Pi conversations

- Pi's latest answer now appears on the iPhone or iPad as it arrives. Before, OpenAI subscription responses arrived without a content type and were not captured, so the answer showed up only after the next prompt.
- The app no longer reports Pi's working/idle state to herdr. herdr now decides the state with its own Pi integration. Without that integration, herdr detects the state from the screen.
- Pi sessions started before this update use the new behavior only after Pi is restarted.

## Notifications

- **An agent has quit while working**: a new notification for an agent that exits while it is working. The agent's pane must stay open, and the agent must have been working within the last 10 seconds. Closing a pane, or exiting an agent more than 10 seconds after it finished, does not notify. It has its own switch in Settings → Notifications, on by default.
- **Dock badge**: the Dock icon shows how many agents are waiting for input, counting machines whose notifications are on. It has its own switch, on by default. If notifications are allowed but badges are turned off in System Settings, Settings → Notifications says so and links there.
- **Machines**: Settings → Notifications lists each registered machine with a switch. A machine turned off is not watched, its shown notifications are removed and it is left out of the badge. Turning it back on does not replay earlier notifications.

## Window and preview

- The main window keeps a minimum size: 400 points of content height, and a width that fits the sidebar (when pinned), the terminal and an open preview or browser panel. Opening a panel can widen the window; closing it does not shrink it.
- Markdown previews with headings have a table of contents that opens from the preview's trailing edge. Selecting a heading scrolls both the rendering and the source to it.
- The title rename field keeps a usable width in narrow windows.

## Fixes

- Fixed a hang when a new Pi tab was added while a proxy check was already running.
- Fixed the lifetime of local terminal attach processes.
- The app now includes Chromium's credits and additional third-party notice attributions.

## Requirements

Universal macOS app for Apple silicon and Intel; macOS 26.6.2 or newer. In-app Browser requires Apple silicon. Experimental features remain opt-in.
