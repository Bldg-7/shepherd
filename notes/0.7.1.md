# hrdrhrdrhrdr 0.7.1

macOS release, build 34.

## Pi conversations with OpenAI / ChatGPT sign-in

Fixes a missing capture path when Pi uses the current **OpenAI** provider with **ChatGPT subscription sign-in**. In 0.7.0, the proxy adapter covered Anthropic and the legacy OpenAI Codex provider, but not the current OpenAI provider. The agent continued working while the paired iPhone or iPad had no captured conversation and showed no Conversation / Screen switch.

- Eligible OpenAI subscription Responses requests now pass through the local conversation proxy.
- Pi's model URL, model catalog, OAuth handling, thinking and cache settings remain unchanged. Only the final eligible HTTP fetch is routed locally.
- API-key authentication, custom endpoints and unrelated requests keep their original transport. The proxy does not become a general-purpose OpenAI endpoint.
- The forwarder recognizes Node fetch's automatic mode header only on the restricted prepared-Pi path. Browser Origin and other browser fetch metadata remain rejected, and private capture headers never reach OpenAI.
- Main requests, compaction and background warming remain distinct. In-memory conversation storage and its limits are unchanged.

## Sidebar selection appearance

Selected pane and tab rows now retain the same native highlighted style whether
the sidebar or terminal has keyboard focus. Clicking a row still gives the
terminal the keyboard; this change affects appearance only. System accent,
light/dark and high-contrast rendering are retained.

## Using the fix

After updating the Mac app, leave **Show Conversations on iPhone and iPad** enabled and start a **new Pi tab from New Tab on This Mac**. Send a message using OpenAI with ChatGPT sign-in, then open that pane on the paired mobile app. Existing running Pi sessions keep the extension with which they started; the update does not restart them.

This capture-path fix is compatible with mobile **0.1.0(4)**. Re-pairing the iPhone or iPad is not required. API-key sign-in, unsupported providers and nested herdr machines remain outside conversation capture.
