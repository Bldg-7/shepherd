# Shepherd 0.3.1

macOS patch release, build 25. Retains all 0.3.0 features.

- Fix the missed remote-unavailable browser caption in Group by Tab: “Remote browser agents unavailable” is no longer shown in the tab list.
- Use the generic “Browser” tooltip for unknown and remote-unavailable browser status. The globe remains neutral; unavailable is not reported as connected. Accessibility retains the actual status.
- Rename the repository README heading to **Shepherd for herdr**.

This is a presentation fix, not new remote-browser support or a change to browser authorization. Experimental browsing remains OFF by default; the existing support boundaries and file-preview limits are unchanged.

Validation: production display-policy compilation/tests, signed universal app, Apple notarization, Sparkle signatures and downloaded delta reconstruction. Installed-app GUI and automatic-update interaction are not exercised by the release checks.
