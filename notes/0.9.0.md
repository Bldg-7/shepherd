# hrdrhrdrhrdr 0.9.0

macOS release, build 38.

This update connects the app to hc, the core of herdr, in place of the herdr command it used until now. It also removes the In-app Browser and the recording of agents' conversations.

## hc in place of herdr

- The app now connects to the official hc 0.1.17 by running `hc connect`, on This Mac and over SSH. It no longer uses the herdr socket or the app's own SSH transport to herdr.
- Install hc on each machine you connect to. When hc is missing or can't be used, the window says why, shows the install command (`curl -fsSL https://releases.herdr.dev/core/install.sh | HC_VERSION=0.1.17 sh`) for you to run, and offers Retry. The app never installs, updates or restarts hc by itself.
- The sidebar, New Tab, Go to Agent or Pane, renaming from the title, Preview, Terminal File Drop and notifications work as before, on hc. Notifications come from hc's own events.
- Panes in a herdr session stay in herdr and keep running, but the app no longer shows them. Open them in herdr, or start new tabs on hc.

## New tabs start agents as plain commands

- Claude Code and Pi start as `claude` and `pi`, as you would start them in a shell, with your own CLI settings. The app adds no extension, MCP server, skill or instructions.
- The one exception is Codex, which starts as `codex --no-daemon`, as in earlier versions.

## Removed

- The In-app Browser, with its settings and its password manager connections.
- The "Show Conversations on iPhone and iPad" setting. The Mac no longer records agents' conversations. The iPhone and iPad app keeps terminal screens and pairing.
- If you turned that setting on in an earlier version, agents started then send their model requests through a local recording proxy that runs in the background. This update leaves the running proxy alone, but the app no longer contains the proxy, so it doesn't start again after you log out or restart. From then on, those agents can't reach their model provider. Start them again from a new tab.

## Requirements

Universal macOS app for Apple silicon and Intel; macOS 26.6.2 or newer; hc 0.1.17 on each machine.
