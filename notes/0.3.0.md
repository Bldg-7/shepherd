# Shepherd 0.3.0

macOS release, build 24. Includes the updates implemented since 0.2.1.

## Machine settings

- Edit registered machines from Settings → Machines using the pencil button.
- Update display name, hostname, port, username and Herdr session while retaining the machine identity and active selection.
- Saved SSH credentials are kept by default and never displayed. Replace them only with the explicit Change Authentication option; failed replacement does not delete the existing credential.
- Connection changes retire stale pane selections and connections. Hostname/port changes reset the saved host-key pin with an explicit warning; renaming alone keeps the connection.

## File preview

- Command-click file paths, file URLs or OSC8 file links in a terminal to open a read-only preview beside it.
- Markdown rendering/source mode, UTF-8 code/text, bitmap-image previews and source-line highlighting.
- Automatic code wrapping follows the current panel width and retains original line numbers. Basic native syntax highlighting supports common languages and Markdown fenced-code labels, with light/dark colors.
- Preview and the embedded browser occupy the same side-panel slot. Switching the displayed panel preserves browser tabs, profiles and agent connections.
- Remote files are read through a separate read-only SFTP connection using that machine's existing credential and host-key pin, never from the Mac's corresponding path. Connect through the normal terminal flow first if the machine has no saved pin.
- Command-click file gestures are captured before terminal mouse reporting: press, drag and release are not sent to the remote TUI. Ordinary clicks retain normal TUI behavior. Read failures never fall back to a remote editor, shell command or local-file opener.
- Only the close control uses a circular native Liquid Glass button. The header refresh button is removed; an explicit retry remains after a read failure.

Preview limits: 4 MiB files, UTF-8 text, 120,000 rendered characters and bounded image thumbnails. No HTML/SVG execution, external-image loading, grammar download or runtime code execution. Syntax highlighting is lexical, not a compiler/language server. Nested Herdr-machine filesystem routing is not supported.

## Terminal and sidebar

- Reserve a fixed gutter outside terminal cells for the focus border, preventing it from covering first-column/bottom-edge text. Focus changes do not move, recreate or resize the terminal; window resizing uses the actual native grid.
- Group by Tab no longer shows pane counts or repeated Browser status unknown captions.
- Pane mode uses a browser-status globe and colors instead of textual browser captions; unknown/unavailable stays neutral, not connected.
- Hide the Pi automatic title prefixes `π - ` and `pi - ` in display titles. Preserve raw titles, session/terminal identity and user-assigned names.

## Compatibility and scope

- Universal macOS app (Apple silicon and Intel); macOS 26.6.2 or newer. Experimental Chromium browsing remains Apple-silicon-only and OFF by default.
- Fresh local session-only managed browser launches for Claude Code, Codex and Pi remain available with the existing pinned/bundled runtime. No global registration, automatic trust approval or replacement of user instructions/extensions.
- Pi saved-session resume, browser-enabled child/headless execution, remote browser routing and native credential autofill remain unsupported/incomplete as documented. Chrome password import/sync is not included.

Validation includes owned SwiftTerm/AppKit geometry and mouse handlers, owned kernel PTY size/input checks, synthetic SFTP/credential seams, title/status policies and full app builds. This is not a claim of live vendor-vault/SSH-account, installed-app GUI or automatic-update acceptance.
