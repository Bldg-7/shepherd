# Shepherd 0.3.2

macOS release, build 26. Includes the updates implemented since 0.3.1.

## Shortcuts that changed

- **⌘N** is New Tab… now. It opens the launcher that ⌘T used to open: pick a machine, then a workspace, then name the tab.
- **⌘T** is New Tab in Current Workspace…. It opens the same launcher with the machine and the workspace of the selected pane or tab already picked, so it starts at the tab's name. Press Backspace to remove the picked workspace or machine and choose another. With no pane or tab selected, it asks for the machine first, as ⌘N does.
- **⌘P** is Go to Agent or Pane…. It was Print.

## One window

- Shepherd has one window. New Window and window tabs are gone.
- Closing the window leaves the app running, as before. Click the Dock icon to bring the window back.

## Go to Agent or Pane…

- It lists every pane of the active machine and of the herdr machines under it. Type to filter by title, agent, pane ID, working directory, or the name of the machine, workspace or tab.
- Choosing an entry shows that pane, or the tab it is in, and puts the keyboard focus in it.

## Sidebar in full screen

- A hidden sidebar comes out as a drawer when the pointer reaches the edge of the screen. The drawer lies over the terminal and takes no width from it.
- To keep the sidebar open beside the terminal, use the sidebar button in the toolbar.

## File preview and links

- A plain click on a file path, a `file://` URL or an OSC 8 link to a file in the terminal opens its preview. Command-click is no longer needed. The click is not sent to the program in the pane; clicks anywhere else are sent as before.
- The preview can be expanded to cover the terminal and restored. Escape restores an expanded preview. When the preview is not expanded, Escape closes it.
- The Markdown preview now lays out ordered lists, nested lists, task lists and pipe tables. A document's leading YAML or TOML frontmatter is shown as rows of keys and values. Setext headings, code fences opened with more than three marks, and block quotes that run over several lines are recognized.
- An `http` or `https` link clicked in the terminal opens in a new tab of that pane's browser. With the experimental browser turned off or unavailable, Shepherd shows an alert instead. It does not hand the link to another app and does not turn the browser on.

## Terminal and settings

- The terminal has a 7pt margin on every side. A pane shown on its own used to have no margin and now has the same 7pt. Such a pane draws no focus border, since there is no other pane to tell it from.
- In Settings → Machines, a row's edit and remove buttons appear only while the pointer is over the row. Both stay in the row's context menu.

## Fixes

- Starting a second Claude Code or Codex in one herdr session works now. Before, Shepherd started every Claude Code under the herdr name "claude" and every Codex under "codex". herdr refuses a name that a running agent already holds, so the second start stopped with `agent_name_taken`, and so did resuming an agent while another pane held its name. Each agent Shepherd starts now gets a name of its own.

## Internal

- Views are drawn through CoreGraphics rather than QuartzCore's in-process Metal renderer. No visible change is expected: the Metal path failed Metal API validation, which stopped debug runs.

## Compatibility and scope

- Universal macOS app (Apple silicon and Intel); macOS 26.6.2 or newer.
- The experimental browser remains OFF by default, and its scope is unchanged from 0.3.1.
- The Markdown preview remains inert: nothing in a document is executed or fetched. The file preview's limits are unchanged from 0.3.1.

Checks made for this release: the usability tests pass on this source; the app is a signed universal build that Apple notarized; the update archive and its deltas carry Sparkle signatures. It was built, signed and notarized by the repository's release workflow on a GitHub-hosted runner. The checks do not operate the installed app's interface or go through an automatic update.
