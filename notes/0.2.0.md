# Shepherd 0.2.0

- Publish the macOS application source alongside the existing website and releases.
- Add an opt-in, pane-scoped Chromium browser using authenticated native transport. Experimental browsing remains OFF by default and requires Apple silicon.
- Prepare bundled browser resources for new Claude Code, Codex and Pi sessions without global MCP/skill installation or runtime package downloads.
- Add Pi 1.1.0 local managed TUI launch with native process/session ownership, lease-scoped browser routes and acknowledged retirement. Supports the built-in MCP backend and pi-mcp-adapter 5.1.0 while preserving user instructions/extensions.
- Simplify Experimental Features settings and diagnostics. Add explicit 1Password app authentication / Service Account choices and Bitwarden connection UI.

## Requirements and limits

macOS 26.6.2+, separately installed Herdr, and the desired agent CLI. Browser resources require Node 20+; Pi requires Node 22.19+.

Pi saved-session resume, child/headless browser reservations, automatic reauthorization when the session ID/file changes, remote browser routing and competing-MCP dispatch suppression are not enabled. Start a fresh managed session when a new browser scope is required.

Credential autofill through the native broker is not complete. Provider connection is not credential-fill authorization. Chrome password import/sync is not included.

## Migration

Do not use the previous global `shepherd-browser` skill/setup scripts. Use Settings → Experimental Features and start a new managed agent tab. Existing global registrations are not silently removed; review and remove only the legacy Shepherd entries with your agent CLI's configuration tools before retrying preparation.
