# Shepherd 0.2.1

- Add a new macOS app icon made with Icon Composer: a white background and a black, close-cropped Shepherd head silhouette, without a collar.
- Keep the white background and black silhouette in Default and Dark appearances; adapt contrast for system Clear/Tinted appearances.
- Include the new icon in both Debug and Release app builds.

This is an icon update. The experimental browser remains OFF by default, and the functionality and support limits documented for 0.2.0 are unchanged.

Sparkle build number: **23** (0.2.0 used build 22).
